# Legacy / alternate Verilog CPU implementation

This source set was extracted from `RISC_16PROJECT.zip` → `src.zip`. It is kept distinct from the separate `risc16-verilog (11).zip` implementation because the files are not identical. The testbench was originally named using a dotless Turkish `ı`; it was renamed to ASCII `risc16_tb.v` for portability without changing the source content.

Compile/test integration is not yet verified. Refer to `ORIGINAL_README.md` for the source archive's original notes.
